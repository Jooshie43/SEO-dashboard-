Professional WordPress theme for home repair and maintenance services with AI-enhanced content and contextual backlink management.

== Description ==

BGK Handy Services is a comprehensive WordPress theme designed specifically for home repair, maintenance, and handyman service businesses. This theme includes:

✓ AI-Enhanced Content Structure
✓ Schema.org Microdata Support
✓ Contextual Backlink Management
✓ Service Portfolio System
✓ Before/After Gallery
✓ Team Showcase
✓ Local SEO Optimization
✓ Mobile Responsive Design
✓ Open Graph & Twitter Card Support
✓ Custom Post Types & Taxonomies
✓ 24/7 Emergency Service Promotion
✓ BBB & Trust Badges Ready

== Installation ==

1. Upload the theme folder to /wp-content/themes/ via FTP
2. Activate the theme from WordPress admin panel
3. Navigate to Appearance → Customize to configure
4. Add your business information in Settings → General
5. Create pages and posts using the custom post types

== Features ==

- Responsive Design: Works perfectly on all devices
- SEO Optimized: Built-in schema markup and meta tags
